内核线程启动入口 — 完成 Schedule() 的锁交接后执行任务函数

Copyright
Copyright The SimpleKernel Contributors

本函数是所有新建内核线程的第一个 C++ 入口。调用链： InitTaskContext 设置 ra=kernel_thread_entry, s0/x19=entry, s1/x20=arg → switch_to 恢复上下文 → ret 到 kernel_thread_entry (汇编) → kernel_thread_entry 将 s0/x19→a0, s1/x20→a1 → call 本函数

锁交接 (Lock Handoff): Schedule() 在持有 sched_lock 的状态下调用 switch_to，将锁的所有权 转移给被切入的任务。对于新任务，本函数负责释放该锁；对于已有任务， Schedule() 中 switch_to 之后的 UnLock() 负责释放。

Parameters
entry线程入口函数，任务结束时必须调用 sys_exit()
arg传递给 entry 的参数
Precondition
当前核心的 sched_lock 由调用 switch_to 的 Schedule() 持有
Postcondition
sched_lock 已释放，中断已恢复，entry(arg) 开始执行
